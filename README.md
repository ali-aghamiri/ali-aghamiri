# Seyyed Ali Aghamiri

M.Sc. researcher in Computer Engineering (Computer Architecture) at the University of Tehran. I work on distributed, networked, and machine learning systems, with an interest in resource scheduling and systems optimization.

**[Academic website](https://ali-aghamiri.github.io/)** · **[CV](https://ali-aghamiri.github.io/assets/Seyyed-Ali-Aghamiri-CV.pdf)** · **[Email](mailto:aghamiri.seyyedali@gmail.com)**

## Research

- **Distributed ML systems:** scheduling across shared compute, storage, and networks, including GPU placement and data prefetching.
- **DAG-based ledgers:** tip selection and transaction prioritization in the IOTA network.
- **Networked media:** low-latency streaming and quality-of-experience analysis.
